# NEXLIX — واجهة عربية مستوحاة من الصورة

مشروع واجهة أمامية متجاوبة باستخدام HTML وCSS وTailwind CSS وhtmx وJavaScript.

## التشغيل
- افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:
  `python -m http.server 8000`
- افتح `http://localhost:8000`

## الملفات
- `index.html`: بنية الصفحة والأقسام.
- `styles.css`: التنسيق والتجاوب مع الهاتف.
- `app.js`: تفاعلات القائمة والبحث وشريط المباراة.
- `search-results.html`: مثال استجابة htmx.

## ملاحظات
- Tailwind CSS وhtmx محمّلان من CDN، لذلك يلزم اتصال بالإنترنت عند فتح الصفحة لأول مرة.
- هذه نسخة واجهة أمامية تجريبية؛ أزرار الاشتراك والمشاهدة تحتاج روابط الخدمة الفعلية.
- الأرقام والملصقات المعروضة بيانات تجريبية قابلة للتغيير.
- لا تتضمن النسخة نظام حسابات أو بثًا أو محتوى محميًا بحقوق نشر.
